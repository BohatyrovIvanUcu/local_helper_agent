### Local Helper Mascot v0.5.0

Швидкий десктопний локальний AI-асистент та інтерактивний маскот на базі **Tauri v2 + Gemini 3.5 Flash-Lite**.

---

### Завантаження та встановлення

#### Linux (Ubuntu / Debian / Mint):
1. Завантажте файл `.deb` нижче в розділі **Assets** (`Local Helper Mascot_0.5.0_amd64.deb` або `local-helper-ai_0.5.0_amd64.deb`).
2. Встановіть через термінал:
```bash
sudo dpkg -i local-helper-ai_0.5.0_amd64.deb
sudo apt-get install -f -y  # за потреби доставити залежності
```

#### Windows (10 / 11):
1. Завантажте інсталятор `.exe` (`Local Helper Mascot_0.5.0_x64-setup.exe`).
2. Запустіть файл та завершіть встановлення у 2 кліки.

#### macOS (Intel / Apple Silicon):
1. Завантажте образ диска `.dmg` (`Local Helper Mascot_0.5.0.dmg`).
2. Відкрийте `.dmg` та перетягніть **Local Helper Mascot** у папку **Applications** (Програми).

### Що нового у версії v0.5.0:

#### 1. Універсальний локальний конвертер файлів (`convert_file`)
- **Інтеграція Microsoft MarkItDown**: конвертація документів, презентацій та електронних таблиць (`.docx`, `.xlsx`, `.pptx`, `.pdf`, `.csv`, `.tsv`, `.html`, `.xml`, `.json`) у структурований Markdown зі збереженням таблиць, списків та заголовків.
- **Векторний рушій експорту нотаток у PDF**: створення PDF-документів із повноцінним текстовим шаром (можливість копіювання, пошуку та виділення тексту) на базі `fpdf2` з автоматичним перенесенням рядків, правильним вирівнюванням полів сторінки та фолбеком на `Pillow`.
- **Медіа-транскодування на базі FFmpeg**:
  - Конвертація відео у GIF із двопрохідним алгоритмом генерації адаптивної палітри (`palettegen` + `paletteuse`), що гарантує високу чіткість без шумів та дизерингу.
  - Вилучення аудіодоріжок з відеофайлів у формати `.mp3`, `.wav`, `.aac`, `.flac`, `.ogg`.
  - Транскодування відео та конвертація графічних форматів (`.png`, `.jpg`, `.webp`, `.ico`, `.bmp`).
- **Архівація папок та файлів**: швидке пакування директорій у стиснені архіви `.zip`, `.tar.gz` або `.tar`.
- **Захист від порожніх файлів**: автоматичний контроль розміру вихідних даних (видалення файлів розміром 0 байт з інформуванням користувача про причину).

#### 2. Розширений Drag-and-Drop
- Реалізовано перетягування будь-яких типів файлів безпосередньо на вікно маскота (відео, документи, аудіо, таблиці, архіви).
- Автоматичне контекстне зв'язування перетягнутого файлу з наступною голосовою або текстовою командою користувача.

#### 3. Інтерактивні дії з файлами у хмаринці діалогу
- Після завершення конвертації маскот виводить клікабельні посилання:
  - **«Відкрити файл»**: миттєвий запуск у системній програмі за замовчуванням (текстовий редактор, PDF-переглядач, медіаплеєр).
  - **«У папці»**: відкриття каталогу з підсвічуванням створеного файлу у системному файловому менеджері (`nautilus --select` на Linux GNOME, `explorer /select` на Windows, `open -R` на macOS).
- Нативна підтримка викликів через підсистему GNOME `gio open` та `xdg-open` із коректною десеріалізацією параметрів Tauri.

#### 4. Покращення інтерфейсу та стабільності
- Збільшено висоту базового вікна маскота до 280 пікселів, оптимізовано відступи та максимальну висоту хмаринки повідомлення (145px) для запобігання вертикальному обрізанню елементів керування.
- Додано рефлекторний Fast-Path для конвертацій: базові запити (`«зроби gif»`, `«конвертуй в md»`, `«перетвори на pdf»`) стартують за <30 мс без звернення до хмарного LLM.
- Оновлено шлюз безпеки `SafetyPolicy`: додано `markitdown` до списку дозволених read-only утиліт.

### Активація ключа Gemini API:
Отримайте безкоштовний ключ на [Google AI Studio](https://aistudio.google.com/) та активуйте його:
- **Linux:** виконайте у терміналі `local-helper-ai addkey <ВАШ_GEMINI_API_KEY>` (або просто `local-helper-ai addkey`).
- **Windows:** виконайте у PowerShell / CMD `local-helper-ai addkey <ВАШ_GEMINI_API_KEY>`.
- **macOS:** виконайте у Terminal `local-helper-ai addkey <ВАШ_GEMINI_API_KEY>`.

### Основні можливості Local Helper Mascot:
- **Конвертація файлів**: документи, таблиці, медіа, PDF, GIF, архіви.
- **Дисплей та звук**: регулювання яскравості, нічного режиму дисплея та системної гучності прямо з чату.
- **Музичний плеєр**: керування YouTube Music / Spotify, анімований стан прослуховування.
- **Розумне саммарі**: конспектування вмісту відкритої вкладки браузера у нотатки Obsidian.
- **Always on Top**: постійна видимість поверх інших вікон (підтримка Wayland та X11).
- **Нагадування та таймери**: системні сповіщення у заданий час із дедуплікацією.
- **Obsidian Kanban**: автоматичне додавання задач та парсинг дедлайнів `@{YYYY-MM-DD}`.
- **Голосове введення**: підтримка розпізнавання аудіо з мікрофона.
