### 🤖 Local Helper Mascot v0.3.2

Десктопний локальний AI-асистент та анімований маскот на базі **Tauri v2 + Gemini 3.5 Flash-Lite**.

---

### 📦 Завантаження та встановлення

#### 🐧 Linux (Ubuntu / Debian / Mint):
1. Завантажте файл `.deb` нижче в розділі **Assets** (`Local Helper Mascot_0.3.2_amd64.deb` або `local-helper-ai_0.3.2_amd64.deb`).
2. Встановіть через термінал:
```bash
sudo dpkg -i local-helper-ai_0.3.2_amd64.deb
sudo apt-get install -f -y  # за потреби доставити залежності
```

#### 🪟 Windows (10 / 11):
1. Завантажте інсталятор `.exe` (`Local Helper Mascot_0.3.2_x64-setup.exe`).
2. Запустіть файл та завершіть встановлення у 2 кліки.

#### 🍏 macOS (Intel / Apple Silicon):
1. Завантажте образ диска `.dmg` (`Local Helper Mascot_0.3.2.dmg`).
2. Відкрийте `.dmg` та перетягніть **Local Helper Mascot** у папку **Applications** (Програми).

### 🚀 Що нового у версії v0.3.2:

- 🎵 **Миттєве керування мультимедіа та YouTube Music (`control_media`)**:
  - Додано пряме перехоплення та миттєве виконання базових медіа-команд (`resume`, `play`, `пауза`, `pause`, `стоп`, `наступний трек`, `next`, `попередній трек`, `prev`) без затримки на виклик LLM (<30 мс).
  - Усунено зависання утиліти `playerctl` на Ubuntu/Linux через перехід на пряму взаємодію з системною шиною MPRIS D-Bus (`org.mpris.MediaPlayer2.Player`) безпосередньо в Snap Firefox, Spotify та Chrome.
  - Виправлено галюцинації Gemini при повторних командах керування медіа та оновлено системні правила обов'язкового виклику `control_media`.

- 📐 **Геометрія вікна та візуальні покращення**:
  - Оптимізовано висоту вікна маскота (258px) та верхній відступ (`pt-6`), усунено обрізання верхнього світлового сяйва (glow) над каскою персонажа.
  - Оптимізовано паралельний запит контексту активного проєкту VS Code без блокування генерації відповіді.

- 🌐 **Розумне саммарі веб-сторінок (`summarize_webpage`)**:
  - Автоматичне знаходження поточної відкритої вкладки у вашому активному браузері (**Firefox / Zen / Chrome / Brave / Chromium / Edge**) або з буфера обміну.
  - Очищення сторінки від реклами та структурований конспект українською мовою з можливістю збереження в Obsidian.

### 🔑 Активація ключа Gemini API:
Отримайте безкоштовний ключ на [Google AI Studio](https://aistudio.google.com/) та активуйте його:
- **Linux:** виконайте у терміналі `addkey <ВАШ_GEMINI_API_KEY>` (або просто `addkey`).
- **Windows:** виконайте у PowerShell / CMD `local-helper-ai addkey <ВАШ_GEMINI_API_KEY>`.
- **macOS:** виконайте у Terminal `local-helper-ai addkey <ВАШ_GEMINI_API_KEY>`.
