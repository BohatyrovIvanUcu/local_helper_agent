### 🤖 Local Helper Mascot v0.2.1

Десктопний локальний AI-асистент та анімований маскот на базі **Tauri v2 + Gemini 3.5 Flash-Lite**.

---

### 📦 Завантаження та встановлення

#### 🐧 Linux (Ubuntu / Debian / Mint):
1. Завантажте файл `.deb` нижче в розділі **Assets** (`local-helper-ai_0.2.1_amd64.deb`).
2. Встановіть через термінал:
```bash
sudo dpkg -i local-helper-ai_0.2.1_amd64.deb
sudo apt-get install -f -y  # за потреби доставити залежності
```

#### 🪟 Windows (10 / 11):
1. Завантажте інсталятор `.exe` (`Local Helper Mascot_0.2.1_x64-setup.exe`).
2. Запустіть файл та завершіть встановлення у 2 кліки.

#### 🍏 macOS (Intel / Apple Silicon):
1. Завантажте образ диска `.dmg` (`Local Helper Mascot_0.2.1.dmg`).
2. Відкрийте `.dmg` та перетягніть **Local Helper Mascot** у папку **Applications** (Програми).

### 🚀 Що нового у версії v0.2.1:

- ⏰ **Нагадування та швидкі таймери (`manage_reminders`)**:
  - Встановлення швидких таймерів («постав таймер на 10 хвилин») та нагадувань на точний час або день («нагадай завтра о 10:00 про лабораторну», «нагадай о 19:30 випити води»).
  - Фоновий планувальник у Rust з підтримкою повторного відтворення пропущених нагадувань після перезавантаження комп'ютера.
  - Подвійне сповіщення: вбудований чистий дзвіночок Web Audio API + системні сповіщення PipeWire (`pw-play`) та `notify-send`.
  - Золотава хмаринка нагадування з анімованим дзвіночком.

- 🎧 **Живий музичний IDLE-режим (`idle-music.png`)**:
  - Коли в системі чи браузері грає музика (YouTube Music, Spotify тощо), маскот автоматично одягає стильні жовто-чорні навушники, бере робочу валізку та ритмічно пританцьовує в такт (head-bobbing) під фіолетовою аурою!
  - Динамічне відстеження через системний D-Bus MPRIS.
  - Точне узгодження масштабу та розмірів зі стандартним станом спокою (без стрибків розміру).

- 🎵 **Повне виправлення відтворення YouTube Music**:
  - Повністю від'єднаний фоновий запуск браузера без блокування UI та зависання на пайпах (`stdout/stderr`).
  - Миттєвий старт персонального плейлиста «Музика, яка сподобалась» та міксу рекомендацій.
  - Обхід блокування автовідтворення у Firefox (Snap Wayland) та Chrome за допомогою нативних політик та емуляції `/dev/uinput`.

- 🧠 **Дворівнева довгострокова пам'ять (`memory.json`)**:
  - Ковзне вікно останніх реплік діалогу + зберігання важливих фактів про вас і ваші робочі каталоги.
  - Зберігається локально між перезапусками, не витрачаючи зайві токени API.

- 🛡️ **Захист від зависання інтерфейсу**:
  - 10-секундний захисний таймаут для виконання будь-яких локальних інструментів.
  - 16-секундний сторожовий таймер та можливість миттєво розблокувати маскота простим кліком.

### 🔑 Активація ключа Gemini API:
Отримайте безкоштовний ключ на [Google AI Studio](https://aistudio.google.com/) та активуйте його:
- **Linux:** виконайте у терміналі `addkey <ВАШ_GEMINI_API_KEY>` (або просто `addkey`).
- **Windows:** виконайте у PowerShell / CMD `local-helper-ai addkey <ВАШ_GEMINI_API_KEY>`.
- **macOS:** виконайте у Terminal `local-helper-ai addkey <ВАШ_GEMINI_API_KEY>`.

### 🛠️ Основні можливості:
- 📌 **Always on Top**: маскот завжди поруч поверх усіх відкритих вікон (підтримка Wayland та X11).
- 🎙️ **Голосове введення**: диктування задач або запитів через мікрофон.
- 📸 **Робота з фото**: вставка скриншотів через `Ctrl+V` або перетягування (drag-and-drop).
- 📋 **Obsidian Kanban**: автоматичний запис задач та дедлайнів у `TODO.md` (`@{YYYY-MM-DD}`) та ідей у колонку `Ideas`.
- ⚙️ **CLI керування**: `local-helper-ai config`, `local-helper-ai set-model`, `local-helper-ai set-vault`, `addkey`.
