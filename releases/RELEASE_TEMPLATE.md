### Local Helper Mascot v0.7.5

Швидкий десктопний локальний AI-асистент та інтерактивний маскот на базі **Tauri v2 + Gemini 3.5 Flash-Lite**.

---

### Завантаження та встановлення

#### Linux (Ubuntu / Debian / Mint):
1. Завантажте файл `.deb` нижче в розділі **Assets** (`Local Helper Mascot_0.7.5_amd64.deb` або `local-helper-ai_0.7.5_amd64.deb`).
2. Встановіть через термінал:
```bash
sudo dpkg -i local-helper-ai_0.7.5_amd64.deb
sudo apt-get install -f -y  # за потреби доставити залежності
```

#### Windows (10 / 11):
1. Завантажте інсталятор `.exe` (`Local Helper Mascot_0.7.5_x64-setup.exe`).
2. Запустіть файл та завершіть встановлення у 2 кліки.

#### macOS (Intel / Apple Silicon):
1. Завантажте образ диска `.dmg` (`Local Helper Mascot_0.7.5.dmg`).
2. Відкрийте `.dmg` та перетягніть **Local Helper Mascot** у папку **Applications** (Програми).

---

### Що нового у версії v0.7.5:

#### 1. Повноцінна розширена інтеграція з Obsidian Vault (`manage_obsidian`)
- **Повноцінне читання нотаток (`read`)**:
  - Асистент тепер може читати вміст будь-яких нотаток у Vault (*«що в моєму TODO»*, *«прочитай нотатку lab ASM»*, *«покажи конспект»*).
  - Автоматичне розпізнавання `.md` розширень та захист від виходу за межі сховища.
- **Повнотекстовий пошук по сховищу (`search`)**:
  - Пошук за ключовими словами у назвах та всередині файлів із виведенням релевантних сніпетів знайдених рядків (*«знайди де я писав про асемблер»*).
- **Створення та оновлення Markdown-нотаток (`create`)**:
  - Створення повноцінних нових нотаток з автоматичним створенням підпапок та безпечним створенням резервних копій `.bak` при перезаписі.
- **Робота зі щоденними нотатками (`daily`)**:
  - Автоматичне відкриття або створення щоденника (`YYYY-MM-DD.md`) із базовим шаблоном дня (*«щоденна нотатка»*, *«запиши думку в щоденник»*).
- **Відмітка виконання та переміщення тасків у TODO/Kanban (`complete_todo`)**:
  - Команда *«я виконав задачу Х»* або *«відміть у TODO як виконано»* автоматично знаходить задачу `- [ ]`, замінює на `- [x]` та переміщує її в секцію `## Completed` / `## DONE`.
- **Перегляд списку файлів (`list`)**:
  - Перегляд дерева нотаток та папок у сховищі з ігноруванням системних директорій (`.obsidian`, `.trash`, `.git`).
- **Зворотна сумісність**:
  - Повністю збережено інструмент `append_to_obsidian` для швидкого додавання тасків, колонок та дедлайнів `@{YYYY-MM-DD}`.

#### 2. Збереження та відновлення робочих сесій («Пресети вкладок»)
- **Миттєве перемикання робочого середовища**: запуск підготовленого стеку посилань та застосунків однією швидкою командою або кліком.
- **Стартовий стек «Навчання» (`study`)**:
  - Автоматичне відкриття вкладки **LMS UCU** (`https://learn.ucu.edu.ua`) у новому вікні браузера.
  - Запуск нативного десктопного застосунку **MS Teams** (`teams-for-linux`).
  - Відкриття редактора коду **VS Code** (`code`).
- **Автоматичне збереження поточної сесії**:
  - Маскот зчитує відкриті вкладки з сеансу браузера (Chrome, Chromium, Brave, Firefox `recovery.jsonlz4`) і зберігає у `~/.config/local-helper-ai/presets.json`.
  - Можливість зберігати власні пресети: *«збережи поточний стек як робота»*, *«збережи сесію як крипта»*.
- **Рефлекторний Fast-Path для пресетів (<30 мс)**:
  - Команди *«відкрий навчання»*, *«навчання»*, *«робочий стек»*, *«покажи мої пресети»* виконуються миттєво без виклику LLM.

#### 3. «Kill Switch» / Блокування при відході від ПК (#50)
- **Миттєве блокування екрана та тиша**: фраза *«я відійшов»*, *«відійшов»*, *«заблокуй екран»*, *«lock»*, *«kill switch»* або *«я пішов»* за <15 мс:
  - Зупиняє будь-яке відтворення музики та мультимедіа через MPRIS D-Bus (YouTube Music, Spotify, плеєри).
  - Блокує системну сесію комп'ютера на рівні ОС (`loginctl lock-session` на Linux Wayland/GNOME, `rundll32` на Windows, `pmset` на macOS).

### Можливості, додані у попередніх релізах (v0.6.0 - v0.6.1):
- **Розархівація та пакування архівів (`convert_file`)**: підтримка zip, tar.gz, 7z, rar з інтерактивними кнопками відкриття розпакованих тек.
- **WizTree (`open_disk_analyzer`)**: інтерактивна карта дискового простору (Squarified Treemap) на SVG.
- **Quick Wi-Fi & HTTPS File Share (`share_file_wifi`)**: роздача файлів на смартфон через QR-код за допомогою захищеного тунелю.
- **Smart Downloads Cleaner (`clean_downloads`)**: автоматичне сортування завантажень та очищення старого мотлоху.

### Активація ключа Gemini API:
Отримайте безкоштовний ключ на [Google AI Studio](https://aistudio.google.com/) та активуйте його:
- **Linux:** виконайте у терміналі `local-helper-ai addkey <ВАШ_GEMINI_API_KEY>` (або просто `local-helper-ai addkey`).
- **Windows:** виконайте у PowerShell / CMD `local-helper-ai addkey <ВАШ_GEMINI_API_KEY>`.
- **macOS:** виконайте у Terminal `local-helper-ai addkey <ВАШ_GEMINI_API_KEY>`.

### Основні можливості Local Helper Mascot:
- **Obsidian Vault & Kanban**: повноцінне читання, створення, повнотекстовий пошук, Daily Notes та закриття задач у TODO.
- **Робочі стеки та пресети вкладок**: відновлення робочих сесій браузера й застосунків в один клік.
- **Розархівація та архівація**: підтримка zip, tar.gz, 7z, rar, tgz з автовизначенням папки.
- **Візуалізація диска WizTree**: інтерактивна карта пам'яті та пошук великих папок.
- **Wi-Fi & HTTPS File Share**: швидка передача файлів на телефон через QR-код.
- **Downloads Cleaner**: автоматичне сортування завантажень та видалення сміття.
- **Конвертація файлів**: MarkItDown, PDF з текстовим шаром, FFmpeg GIF/Audio/Video.
- **Дисплей та звук**: нативне керування яскравістю, нічним світлом та гучністю.
- **Музичний плеєр**: керування YouTube Music / Spotify через MPRIS D-Bus.
- **Розумне саммарі**: конспектування вмісту відкритої вкладки браузера у нотатки Obsidian.
- **Always on Top**: постійна видимість поверх інших вікон (Wayland та X11).
- **Нагадування та таймери**: системні сповіщення у заданий час із дедуплікацією.
- **Голосове введення**: підтримка розпізнавання аудіо з мікрофона.
