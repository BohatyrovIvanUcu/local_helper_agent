### 🤖 Local Helper Mascot v0.3.1

Десктопний локальний AI-асистент та анімований маскот на базі **Tauri v2 + Gemini 3.5 Flash-Lite**.

---

### 📦 Завантаження та встановлення

#### 🐧 Linux (Ubuntu / Debian / Mint):
1. Завантажте файл `.deb` нижче в розділі **Assets** (`Local Helper Mascot_0.3.1_amd64.deb` або `local-helper-ai_0.3.1_amd64.deb`).
2. Встановіть через термінал:
```bash
sudo dpkg -i local-helper-ai_0.3.1_amd64.deb
sudo apt-get install -f -y  # за потреби доставити залежності
```

#### 🪟 Windows (10 / 11):
1. Завантажте інсталятор `.exe` (`Local Helper Mascot_0.3.1_x64-setup.exe`).
2. Запустіть файл та завершіть встановлення у 2 кліки.

#### 🍏 macOS (Intel / Apple Silicon):
1. Завантажте образ диска `.dmg` (`Local Helper Mascot_0.3.1.dmg`).
2. Відкрийте `.dmg` та перетягніть **Local Helper Mascot** у папку **Applications** (Програми).

---

### 🚀 Що нового у версії v0.3.1:

- 🌐 **Розумне саммарі веб-сторінок (`summarize_webpage`)**:
  - Автоматично знаходить поточну відкриту вкладку у вашому активному браузері (**Firefox / Zen / Chrome / Brave / Chromium / Edge**) або бере посилання з буфера обміну чи тексту запиту.
  - Очищує сторінку від реклами, банерів і навігації, витягуючи чистий текст статті, та формує структурований конспект українською мовою (або одразу зберігає його у нотатку Obsidian чи текстовий файл).
  - Ізольована обробка зовнішнього веб-контенту (`<untrusted_web_content>`) із захистом від prompt-injection.

- 🩹 **Виправлення зависання та неклікабельності вікна на старті системи (Linux / GNOME Wayland)**:
  - Усунено стан перегонів між XWayland та Mutter (`meta_window_set_stack_position_no_sync: stack_position >= 0`), через який при холодному старті ПК або перезапуску маскот міг зависати посеред екрана й пропускати кліки миші крізь себе.
  - Примусове перемикання на `GDK_BACKEND=x11` (навіть якщо сесія виставила `GDK_BACKEND=wayland`), автоматичне скидання `input_shape` після мапінгу вікна та автозавершення попередніх завислих процесів при перезапуску.

- 🧩 **Нативна архітектура агентського циклу та контекст VS Code**:
  - Нативний Gemini Function Calling із детермінованим багатокроковим оркестратором та шлюзом безпеки `SafetyPolicy`.
  - Автоматичне визначення поточного відкритого проєкту (workspace) та активного файлу у VS Code / Cursor / VSCodium.
  - Розгортання та згортання вікна відповіді маскота для зручного читання довгих саммарі.

### 🔑 Активація ключа Gemini API:
Отримайте безкоштовний ключ на [Google AI Studio](https://aistudio.google.com/) та активуйте його:
- **Linux:** виконайте у терміналі `addkey <ВАШ_GEMINI_API_KEY>` (або просто `addkey`).
- **Windows:** виконайте у PowerShell / CMD `local-helper-ai addkey <ВАШ_GEMINI_API_KEY>`.
- **macOS:** виконайте у Terminal `local-helper-ai addkey <ВАШ_GEMINI_API_KEY>`.
