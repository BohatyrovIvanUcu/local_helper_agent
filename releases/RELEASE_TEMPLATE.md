### Local Helper Mascot v0.6.0

Швидкий десктопний локальний AI-асистент та інтерактивний маскот на базі **Tauri v2 + Gemini 3.5 Flash-Lite**.

---

### Завантаження та встановлення

#### Linux (Ubuntu / Debian / Mint):
1. Завантажте файл `.deb` нижче в розділі **Assets** (`Local Helper Mascot_0.6.0_amd64.deb` або `local-helper-ai_0.6.0_amd64.deb`).
2. Встановіть через термінал:
```bash
sudo dpkg -i local-helper-ai_0.6.0_amd64.deb
sudo apt-get install -f -y  # за потреби доставити залежності
```

#### Windows (10 / 11):
1. Завантажте інсталятор `.exe` (`Local Helper Mascot_0.6.0_x64-setup.exe`).
2. Запустіть файл та завершіть встановлення у 2 кліки.

#### macOS (Intel / Apple Silicon):
1. Завантажте образ диска `.dmg` (`Local Helper Mascot_0.6.0.dmg`).
2. Відкрийте `.dmg` та перетягніть **Local Helper Mascot** у папку **Applications** (Програми).

### Що нового у версії v0.6.0:

#### 1. WizTree — Візуалізатор дискового простору (`open_disk_analyzer`)
- **Повнорозмірне інтерактивне вікно**: окреме вікно аналізу дисків та папок у темному мінімалістичному дизайні (`index.html?view=disk_analyzer`).
- **Squarified Treemap (Інтерактивна карта блоків)**: візуалізація дискового простору на чистому векторному SVG без важких залежностей. Розмір кожного прямокутника пропорційний реальному об'єму на диску.
- **Дерево файлової системи (Tree View)**: розгортання директорій, підрахунок розміру, кількості елементів та візуальні смужки заповнення `% of parent`.
- **Таблиця розширень**: зведення за типами файлів (`.mp4`, `.zip`, `.node_modules`, `.iso` тощо) з кольоровими маркерами, що відповідають блокам на карті.
- **Контекстне меню**: клік правою кнопкою миші на будь-якому блоці чи рядку дерева дозволяє миттєво відкрити файл/папку в системному файловому менеджері, очистити вміст або безпечно перемістити в кошик.
- **Швидкий запуск (Fast-Path)**: команди *«що забило диск»*, *«wiztree»*, *«аналізатор диска»*, *«де місце на диску»* відкривають карту за <30 мс.

#### 2. Quick Wi-Fi & HTTPS File Share — Роздача файлів на смартфон (`share_file_wifi`)
- **Пряма передача без шнурів і месенджерів**: відправка будь-яких файлів та папок (з автоматичним створенням ZIP-архіву на льоту) прямо на екран телефону через сканування QR-коду.
- **Подвійний режим (Dual Mode)**:
  - **🔒 Захищений HTTPS-тунель (Tunnelmole)**: публічне безпечне посилання зі справжнім глобальним SSL-сертифікатом Let's Encrypt. Працює у будь-яких мережах (мобільний інтернет 4G/LTE, університетський Wi-Fi, ізольовані гостьові мережі), не блокується автоматичним HTTPS-захистом Android Chrome.
  - **📶 Локальний Wi-Fi (LAN)**: пряма віддача всередині локальної мережі на максимальній швидкості вашого роутера.
- **Інтерактивний перемикач режимів**: вкладки перемикання між HTTPS та LAN прямо у вікні роздачі з миттєвим оновленням QR-коду.
- **Адаптивна сторінка завантаження**: мобільний інтерфейс із прев'ю зображень, відео та аудіо, коректним кодуванням імен файлів (RFC 5987 / UTF-8) та індикацією процесу передачі в реальному часі.

#### 3. Smart Downloads Cleaner — Автоматичне прибирання `~/Downloads` (`clean_downloads`)
- **Категоризація файлів**: інтелектуальне сортування завантажень за теками: *Документи*, *Зображення*, *Відео*, *Аудіо*, *Архіви*, *Інсталятори*, *Код*.
- **Правило «Топ-5 найновіших»**: 5 найновіших файлів залишаються недоторканими в корені `~/Downloads`, щоб не переривати поточну роботу користувача.
- **Виявлення непотребу**: автоматичний пошук незавершених файлів (`.crdownload`, `.part`), старих інсталяторів (`.deb`, `.iso`, `.AppImage`) віком понад 30 днів та дублікатів з суфіксами копій `*(1).*`, `*(2).*`.
- **Безпека**: перед виконанням прибирання маскот показує детальний звіт із можливістю підтвердження.
- **Швидкий запуск (Fast-Path)**: команди *«прибери завантаження»*, *«очисти downloads»*, *«порядок в завантаженнях»*.

#### 4. Мульти-віконна архітектура Tauri v2 та надійність
- Реалізовано чистий поділ нативних вікон: легкий маскот (280x280 / 380x440) делегує важкі інтерфейси (WizTree, Wi-Fi Share) незалежним нативним вікнам WebviewWindow із власними обробниками життєвого циклу.
- Усунено конфлікти паралельних сесій роздачі: стабільний життєвий цикл фонових тунелів без ризику закриття з'єднання чи переривання завантаження.
- Оновлено шлюз безпеки `SafetyPolicy`: нові інструменти інтегровані в матрицю дозволів без потреби зайвих запитів прав.

### Активація ключа Gemini API:
Отримайте безкоштовний ключ на [Google AI Studio](https://aistudio.google.com/) та активуйте його:
- **Linux:** виконайте у терміналі `local-helper-ai addkey <ВАШ_GEMINI_API_KEY>` (або просто `local-helper-ai addkey`).
- **Windows:** виконайте у PowerShell / CMD `local-helper-ai addkey <ВАШ_GEMINI_API_KEY>`.
- **macOS:** виконайте у Terminal `local-helper-ai addkey <ВАШ_GEMINI_API_KEY>`.

### Основні можливості Local Helper Mascot:
- **Візуалізація диска WizTree**: інтерактивна карта пам'яті та пошук великих папок.
- **Wi-Fi & HTTPS File Share**: швидка передача файлів на телефон через QR-код.
- **Downloads Cleaner**: автоматичне сортування завантажень та видалення сміття.
- **Конвертація файлів**: MarkItDown, PDF з текстовим шаром, FFmpeg GIF/Audio/Video.
- **Дисплей та звук**: нативне керування яскравістю, нічним світлом та гучністю.
- **Музичний плеєр**: керування YouTube Music / Spotify через MPRIS D-Bus.
- **Розумне саммарі**: конспектування вмісту відкритої вкладки браузера у нотатки Obsidian.
- **Always on Top**: постійна видимість поверх інших вікон (Wayland та X11).
- **Нагадування та таймери**: системні сповіщення у заданий час із дедуплікацією.
- **Obsidian Kanban**: автоматичне додавання задач та парсинг дедлайнів `@{YYYY-MM-DD}`.
- **Голосове введення**: підтримка розпізнавання аудіо з мікрофона.
