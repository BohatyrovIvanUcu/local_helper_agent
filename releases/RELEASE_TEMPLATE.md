### Local Helper Mascot v0.6.1

Швидкий десктопний локальний AI-асистент та інтерактивний маскот на базі **Tauri v2 + Gemini 3.5 Flash-Lite**.

---

### Завантаження та встановлення

#### Linux (Ubuntu / Debian / Mint):
1. Завантажте файл `.deb` нижче в розділі **Assets** (`Local Helper Mascot_0.6.1_amd64.deb` або `local-helper-ai_0.6.1_amd64.deb`).
2. Встановіть через термінал:
```bash
sudo dpkg -i local-helper-ai_0.6.1_amd64.deb
sudo apt-get install -f -y  # за потреби доставити залежності
```

#### Windows (10 / 11):
1. Завантажте інсталятор `.exe` (`Local Helper Mascot_0.6.1_x64-setup.exe`).
2. Запустіть файл та завершіть встановлення у 2 кліки.

#### macOS (Intel / Apple Silicon):
1. Завантажте образ диска `.dmg` (`Local Helper Mascot_0.6.1.dmg`).
2. Відкрийте `.dmg` та перетягніть **Local Helper Mascot** у папку **Applications** (Програми).

### Що нового у версії v0.6.1:

#### 1. Повноцінна розархівація та розпакування архівів (Unarchive / Extract)
- **Універсальна підтримка форматів**: маскот тепер вміє не лише пакувати папки в архіви, але й розпаковувати будь-які типи архівів: `.zip`, `.tar.gz`, `.tgz`, `.tar.bz2`, `.tar.xz`, `.tar`, `.7z`, `.rar`.
- **Автоматична цільова директорія**: розумне очищення подвійних розширень (наприклад, `project.tar.gz` розпаковується в окрему охайну папку `project/` поруч із архівом). У разі колізії автоматично обирається безпечне унікальне ім'я (`project_1/`).
- **Багаторівневі нативні рушії**:
  - Для `.zip`: нативний `unzip -q -o` з фолбеком на Python `shutil.unpack_archive(..., 'zip')`.
  - Для `.tar`, `.tar.gz`, `.tgz`, `.tar.bz2`, `.tar.xz`: нативний `tar -xf` з фолбеком на Python `shutil`.
  - Для `.7z` та `.rar`: утиліти `7z` / `unrar` з надійним фолбеком.
  - Універсальний аварійний обробник для нестандартних архівів через стандартну бібліотеку Python 3.
- **Підрахунок об'єму та безпека**: рекурсивний прорахунок розміру розпакованих директорій, усунення помилок перевірки порожнього файлу для тек.
- **Інтерактивні кнопки в чаті**: після розпакування одразу з'являються клікабельні посилання `[Відкрити папку]` та `[У файловому менеджері]`.

#### 2. Рефлекторний Fast-Path для розархівації (<30 мс)
- Миттєве виконання команд без звернення до нейромережі, без затримок і без використання інтернет-трафіку/токенів API:
  - *«розархівуй /шлях/до/архіву.zip»*
  - *«розпакуй archive.tar.gz»*
  - *«видобудь вміст backup.7z»*
  - *«unzip package.zip»*
  - *«витягни з архіву в папку»*

#### 3. Оновлення моделі LLM Function Calling (`convert_file`)
- Інструмент `convert_file` у Gemini розширено діями `unzip`, `extract`, `unarchive`. Модель може інтелектуально розпаковувати архіви у складі складних багатоходових ланцюжків команд (наприклад: *«завантаж файл, розпакуй його та знайди всередині PDF»*).

### Можливості, додані у версії v0.6.0:
- **WizTree (`open_disk_analyzer`)**: інтерактивна карта дискового простору (Squarified Treemap) на SVG, дерево файлів та підрахунок ваги розширень.
- **Quick Wi-Fi & HTTPS File Share (`share_file_wifi`)**: роздача файлів на смартфон через QR-код за допомогою захищеного HTTPS-тунелю (Tunnelmole) або прямого LAN-підключення.
- **Smart Downloads Cleaner (`clean_downloads`)**: автоматичне прибирання директорії `~/Downloads` з правилом збереження топ-5 найновіших файлів.

### Активація ключа Gemini API:
Отримайте безкоштовний ключ на [Google AI Studio](https://aistudio.google.com/) та активуйте його:
- **Linux:** виконайте у терміналі `local-helper-ai addkey <ВАШ_GEMINI_API_KEY>` (або просто `local-helper-ai addkey`).
- **Windows:** виконайте у PowerShell / CMD `local-helper-ai addkey <ВАШ_GEMINI_API_KEY>`.
- **macOS:** виконайте у Terminal `local-helper-ai addkey <ВАШ_GEMINI_API_KEY>`.

### Основні можливості Local Helper Mascot:
- **Розархівація та архівація**: підтримка zip, tar.gz, 7z, rar, tgz з автовизначенням папки.
- **Візуалізація диска WizTree**: інтерактивна карта пам'яті та пошук великих папок.
- **Wi-Fi & HTTPS File Share**: швидка передача файлів на телефон через QR-код.
- **Downloads Cleaner**: автоматичне сортування завантажень та видалення сміття.
- **Конвертація файлів**: MarkItDown, PDF з текстовим шаром, FFmpeg GIF/Audio/Video.
- **Дисплей та звук**: нативне керування яскравістю, нічним світлом та гучністю.
- **Музичний плеєр**: керування YouTube Music / Spotify через MPRIS D-Bus.
- **Розумне саммарі**: конспектування вмісту відкритої вкладки браузера у нотатки Obsidian.
- **Always on Top**: постійна видимість поверх інших вікон (Wayland та X11).
- **Нагадування та таймери**: системні сповіщення у заданий час із дедуплікацією.
- **Obsidian Kanban**: автоматичне додавання задач та парсинг дедлайнів `@{YYYY-MM-DD}`.
- **Голосове введення**: підтримка розпізнавання аудіо з мікрофона.
