### 🤖 Local Helper Mascot v0.4.0

Швидкий десктопний локальний AI-асистент та інтерактивний маскот на базі **Tauri v2 + Gemini 3.5 Flash-Lite**.

---

### 📦 Завантаження та встановлення

#### 🐧 Linux (Ubuntu / Debian / Mint):
1. Завантажте файл `.deb` нижче в розділі **Assets** (`Local Helper Mascot_0.4.0_amd64.deb` або `local-helper-ai_0.4.0_amd64.deb`).
2. Встановіть через термінал:
```bash
sudo dpkg -i local-helper-ai_0.4.0_amd64.deb
sudo apt-get install -f -y  # за потреби доставити залежності
```

#### 🪟 Windows (10 / 11):
1. Завантажте інсталятор `.exe` (`Local Helper Mascot_0.4.0_x64-setup.exe`).
2. Запустіть файл та завершіть встановлення у 2 кліки.

#### 🍏 macOS (Intel / Apple Silicon):
1. Завантажте образ диска `.dmg` (`Local Helper Mascot_0.4.0.dmg`).
2. Відкрийте `.dmg` та перетягніть **Local Helper Mascot** у папку **Applications** (Програми).

### 🚀 Що нового у версії v0.4.0:

- ☀️ **Керування яскравістю екрана та нічним світлом (№23)**:
  - **GNOME Mutter D-Bus (`SetBacklight`)**: апаратна зміна яскравості екрана за ~4 мс без відкриття налаштувань (*«зменш яскравість до 30%»*, *«яскравість 80%»*, *«зроби яскравіше»*).
  - **Нічний режим (`Night Light`)**: швидке перемикання колірної температури дисплея через `gsettings` (*«увімкни нічне світло»*, *«теплий екран»*, *«холодний екран»*).
  - Надійні фолбеки для інших оточень: `brightnessctl`, `xrandr`, Windows WMI та macOS `brightness`.

- 🔊 **Нативна системна гучність (PipeWire / ALSA)**:
  - Пряма підтримка аудіосервера **PipeWire** (`wpctl`), а також PulseAudio (`pactl`), `amixer` та macOS `osascript`.
  - Миттєве встановлення гучності у відсотках, плавне регулювання кроком ±10% та повний Mute/Unmute (*«звук на 0»*, *«гучність 50%»*, *«тихіше»*, *«голосніше»*).

- ⚡ **Рефлекторний Fast-Path (<30 мс) та розмовні команди**:
  - Команди керування медіа (пауза, відновлення, наступний трек, попередній трек, скіп, гучність) та екраном перехоплюються на фронтенді та виконуються миттєво напряму через Rust-бекенд.
  - Повне розпізнавання живих розмовних фраз та сленгу: *«next song»*, *«скіпни трек»*, *«перемкни пісню»*, *«музику сер»*, *«офни музику пж»*, *«потуши музику треба тиші»*, *«зроби музику вполовину тихіше»*, *«зроби теплий екран»*, *«холодний екран»*, *«чскравіть на 70»*, *«зроби екран темніше»*.
  - Нуль мережевої затримки, нуль витрат токенів Gemini API.

- 🧠 **Прозорий аудит дій у пам'яті (`tools_used`) та захист від галюцинацій**:
  - Усі фактично виконані інструменти (і через Fast-Path, і через LLM Tool Calling) автоматично записуються у `memory.json` та `agent.jsonl` у полі `tools_used`.
  - **Комплексний захист для всіх 9 інструментів**: суворі правила в системному промпті для задач, медіа, яскравості/екрана, нагадувань/таймерів, пам'яті, веб-саммарі та файлів.
  - **Динамічна санітизація історії розмов**: якщо в історії є старі репліки, де помічник відповідав текстом без реального виклику інструменту, вони автоматично виключаються з контексту Gemini API, щоб не отруювати поведінку моделі.

- 🏗️ **Модульна декомпозиція бекенду (Rust / Tauri)**:
  - Монолітний `lib.rs` (3800 рядків) розбито на 13 ізольованих модулів: `audio`, `display`, `media`, `obsidian`, `reminders`, `files`, `workspace`, `memory`, `voice`, `clipboard`, `web`, `window`, `config`.
  - Створено фундаментальний файл стандартів та архітектури проєкту: `GEMINI.md`.

### 🔑 Активація ключа Gemini API:
Отримайте безкоштовний ключ на [Google AI Studio](https://aistudio.google.com/) та активуйте його:
- **Linux:** виконайте у терміналі `local-helper-ai addkey <ВАШ_GEMINI_API_KEY>` (або просто `local-helper-ai addkey`).
- **Windows:** виконайте у PowerShell / CMD `local-helper-ai addkey <ВАШ_GEMINI_API_KEY>`.
- **macOS:** виконайте у Terminal `local-helper-ai addkey <ВАШ_GEMINI_API_KEY>`.

### 🛠️ Основні можливості Local Helper Mascot:
- ☀️ **Дисплей та звук**: миттєве регулювання яскравості, нічного світла та гучності прямо з чату.
- 🎧 **Живий музичний режим**: керування YouTube Music / Spotify та анімований маскот у навушниках.
- 🌐 **Розумне саммарі**: «зроби саммарі відкритої вкладки», конспектування статей у нотатки Obsidian.
- 📌 **Always on Top**: маскот завжди поверх усіх відкритих вікон (підтримка Wayland та X11).
- ⏰ **Нагадування та таймери**: системні звукові та візуальні сповіщення у заданий час.
- 🎙️ **Голос та зображення**: розпізнавання голосу через мікрофон, читання скриншотів із буфера обміну.
- 📋 **Obsidian Kanban**: інтеграція з дошками задач, колонка `Ideas` та дедлайни `@{YYYY-MM-DD}`.
