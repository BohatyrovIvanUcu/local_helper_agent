# Local Helper Mascot 🤖🔨

Десктопний локальний AI-асистент та анімований маскот на базі **Tauri v2 + React 18 (TypeScript) + Tailwind CSS + Framer Motion**, що використовує мультимодальний інтелект **Google Gemini API** (`gemini-3.5-flash-lite` за замовчуванням) та виконує локальні операції на вашому комп'ютері через надійні асинхронні команди Rust.

![Mascot Preview](public/mascot/idle.png)

## ⚡ Швидкий старт для користувачів

Усі версії програми збираються автоматично для **Linux, Windows та macOS** і доступні для завантаження у розділі **[GitHub Releases](https://github.com/BohatyrovIvanUcu/local_helper_agent/releases)** або в артефактах **[GitHub Actions](https://github.com/BohatyrovIvanUcu/local_helper_agent/actions)**.

### 1. Завантаження та встановлення

#### 🐧 Linux (Ubuntu / Debian / Linux Mint):
```bash
# Встановлення deb-пакета версії 0.3.2:
sudo dpkg -i releases/local-helper-ai_0.3.2_amd64.deb

# Якщо системі потрібні залежності (GTK3 / WebKit2GTK):
sudo apt-get install -f -y
```
Після встановлення програма з'явиться у системному меню як **"Local Helper Mascot"**, а в терміналі будуть доступні команди `local-helper-ai` та `addkey`.

#### 🪟 Windows (10 / 11):
1. Завантажте файл `Local Helper Mascot_*_x64-setup.exe` з [Releases](https://github.com/BohatyrovIvanUcu/local_helper_agent/releases).
2. Запустіть інсталятор. Програма створить ярлики в меню «Пуск» та на робочому столі.

#### 🍏 macOS (Intel & Apple Silicon M-серія):
1. Завантажте файл `.dmg` з [Releases](https://github.com/BohatyrovIvanUcu/local_helper_agent/releases).
2. Відкрийте `.dmg` та перетягніть іконку маскота у папку **Applications** (Програми).

## 🔑 Як отримати безкоштовний Gemini API ключ

Маскот використовує офіційний Google Gemini API. Для роботи достатньо безкоштовного тарифу (Free Tier), який надає Google.

### Покрокова інструкція:

1. **Перейдіть на сайт Google AI Studio:**  
   👉 [https://aistudio.google.com/](https://aistudio.google.com/)
2. **Увійдіть під своїм Google-акаунтом.**
3. У верхньому лівому кутку натисніть синю кнопку **"Get API key"** (або "Create API key").
4. Натисніть **"Create API key in new project"** (або виберіть існуючий проєкт Google Cloud).
5. Скопіюйте створений ключ (він починається на `AIzaSy...`).

> [!NOTE]  
> Ключ зберігається виключно на вашому власному комп'ютері у локальному файлі конфігурації `~/.config/local-helper-ai/config.env` і ніколи не передається третім особам.

## 💻 Налаштування через термінал (`addkey` та CLI)

Після встановлення програми ви можете зручно керувати всіма налаштуваннями через термінал:

### 1. Додати або оновити Gemini API ключ:

- **На Linux:**
  ```bash
  # Пряме додавання ключа:
  addkey AIzaSyВаш_Ключ_З_Google_AI_Studio

  # Або виконайте команду без аргументів для інтерактивного введення:
  addkey
  ```
- **На Windows (PowerShell або CMD):**
  ```powershell
  local-helper-ai addkey AIzaSyВаш_Ключ
  ```
- **На macOS (Terminal):**
  ```bash
  local-helper-ai addkey AIzaSyВаш_Ключ
  ```

### 2. Змінити модель Gemini:

За замовчуванням використовується модель `gemini-3.5-flash-lite`. Ви можете перемкнути її на будь-яку іншу:

```bash
# Перемкнути на повнорозмірну модель Flash:
local-helper-ai set-model gemini-3.8-flash

# Повернути модель за замовчуванням:
local-helper-ai set-model gemini-3.5-flash-lite
```

### 3. Підключити сховище нотаток Obsidian (Obsidian Vault):

Вкажіть маскоту, де знаходиться ваше сховище Obsidian, щоб він міг автоматично додавати задачі та ідеї у ваш канбан:

```bash
local-helper-ai set-vault ~/Documents/Obsidian/MyVault
```

### 4. Переглянути поточну конфігурацію:

```bash
local-helper-ai config
```

Ви побачите статус усіх параметрів:
```text
==================================================
🤖 Local Helper Mascot — Поточна конфігурація
==================================================
📁 Файл конфігурації : /home/user/.config/local-helper-ai/config.env
🔑 Gemini API Key    : AIzaSy...xxxx (Встановлено ✅)
🧠 Модель Gemini     : gemini-3.5-flash-lite
📝 Obsidian Vault    : /home/user/Documents/Obsidian/MyVault ✅
==================================================
```

### 5. Змінити будь-який довільний параметр:

```bash
local-helper-ai set ІМ'Я_ПАРАМЕТРА ЗНАЧЕННЯ
```

### 6. Довідка за всіма командами:

```bash
local-helper-ai --help
```

## 🛠️ Можливості та сценарії використання

### 1. 🎵 Мультимедіа та Системний Звук

Маскот підтримує як **надшвидке локальне виконання базових команд без звернення до LLM (<30 мс)**, так і складні розмовні запити пошуку музики. Працює з **YouTube Music, Spotify, VLC** та системною шиною **MPRIS D-Bus**.

- **Швидкі медіа-команди (<30 мс, без виклику Gemini):**
  - `пауза`, `pause`, `стоп` — миттєво зупиняє активний плеєр (маскот скидає навушники).
  - `грай`, `play`, `продовжи`, `resume` — відновлює відтворення (маскот одягає навушники та танцює).
  - `наступний трек`, `next`, `скіп` — перемикає на наступну пісню.
  - `попередній трек`, `prev`, `назад` — повертає попередню пісню.
- **Пошук та запуск музики у YouTube Music:**
  - `«включи Скрябіна»`, `«увімкни lofi beats»`, `«знайди рок»` — знаходить трек та запускає його з обходом блокування автовідтворення.
  - `«включи мої лайки»`, `«грай улюблену музику»` — відкриває персональний плейлист вподобаних треків (`watch?list=LM`).
  - `«включи рекомендації»`, `«мій мікс»` — запускає персональний нескінченний мікс треків (`watch?list=RDMM`).
- **Керування системною гучністю (без модальних вікон підтвердження):**
  - Виконується автоматично через системні утиліти `pactl`, `wpctl`, `pamixer`, `amixer`, `osascript`.
  - `«зроби голосніше»` / `«зроби тихіше»`
  - `«постав гучність на 50%»` / `«звук 80%»`
  - `«вимкни звук»` (mute) / `«увімкни звук»` (unmute)

### 2. 📋 Obsidian Kanban та Задачі

Глибока інтеграція з локальним сховищем **Obsidian Vault**. Маскот автоматично розпізнає дедлайни з живої мови та записує їх у форматі плагіна **Obsidian Kanban** (`@{YYYY-MM-DD}`).

- **Задачі в колонку `## TO DO`:**
  - `«запиши задачу доробити звіт до завтра 18:00»`  
    👉 Створює рядок: `- [ ] доробити звіт @{2026-10-25} 18:00` у файлі `TODO.md`.
  - `«додай справу купити каву в четвер»`  
    👉 Автоматично вираховує точну дату найближчого четверга.
- **Ідеї в колонку `## Ideas`:**
  - `«запиши ідею для стартапу: автоматичний мікромаркет»`
- **Нотатки в щоденний журнал:**
  - `«додай нотатку про зустріч у щоденний журнал»`

### 3. 🌐 Розумне Саммарі Веб-сторінок

Інструмент `summarize_webpage` уміє самостійно знаходити поточну активну вкладку у вашому браузері (**Firefox, Google Chrome, Brave, Zen, Edge, Chromium**) або брати скопійований текст з буфера обміну.

- **Авто-саммарі відкритої вкладки:**
  - `«зроби саммарі цієї статті»` або `«про що ця сторінка?»`.
  - Маскот автоматично очищує сторінку від реклами, скриптів і навігації та формує конспект на 3–5 ключових тез.
- **Саммарі за прямим посиланням або фокусом:**
  - `«зроби саммарі https://uk.wikipedia.org/... з акцентом на біографії»`.
- **Підтримка SPA-сайтів та закритих адмінок (Clipboard Fallback):**
  - Якщо сторінка динамічна (React, Next.js) чи вимагає авторизації — виділіть текст (`Ctrl+C`) і скажіть: `«зроби саммарі скопійованого»`.
- **Захист від Prompt Injection:** Вміст зовнішніх сайтів ізолюється всередині захищеного контексту безпеки.

### 4. ⏰ Таймери та Нагадування

Вбудований локальний планувальник із надійним сповіщенням через системний звуковий сигнал (`paplay`) та виринаюче вікно.

- **Швидкі таймери:**
  - `«постав таймер на 5 хвилин»` або `«таймер на 45 секунд»`
- **Нагадування на час чи день:**
  - `«нагадай випити води через 20 хвилин»`
  - `«нагадай зателефонувати колезі завтра о 10:30»`
  - `«нагадай у п'ятницю о 14:00 здати звіт»`
- **Перегляд і скасування:**
  - `«які в мене таймери?»`, `«скасуй нагадування про воду»`, `«скасуй усі нагадування»`.
- **Захист від пропущених подій:** Якщо комп'ютер чи маскот були вимкнені в момент настання дедлайну, при наступному старті помічник обов'язково сповістить:  
  *«🔔 Поки я був вимкнений, минув час: зателефонувати колезі»*.

### 5. 🎙️ Голосове Введення та 📸 Робота із Зображеннями

- **🎙️ Голосове диктування (Gemini STT):**
  - Клікніть по іконці мікрофона поруч із рядком вводу.
  - Надиктуйте команду голосом (працює таймер запису).
  - Натисніть кнопку мікрофона ще раз або `Enter` — голос розпізнається та виконається.
- **📸 Вставка скриншотів (`Ctrl+V` та `Ctrl+М`):**
  - Зробіть скриншот (`PrintScreen`), відкрийте маскота і натисніть `Ctrl+V` (або `Ctrl+М` в українській розкладці).
  - Зображення прикріплюється миттєво з інтерактивним прев'ю.
- **🖼️ Drag-and-Drop:**
  - Перетягніть будь-який файл `.png`, `.jpg`, `.webp` мишкою прямо на тіло маскота.
- **Аналіз зображень через Gemini Vision:**
  - `«проаналізуй цей скриншот»`
  - `«розпізнай помилку в терміналі на цьому фото»`
  - `«запиши задачі з цього розкладу в Obsidian»`

### 6. 💻 Інтеграція з VS Code та Робота з Файлами

- **Автоматичне визначення контексту розробника:**
  - Маскот самостійно визначає активний робочий проєкт та відкритий файл у **VS Code / Cursor / VSCodium**.
  - `«який у мене зараз відкритий проєкт і файл?»`.
  - При роботі з файлами без явного шляху маскот автоматично орієнтується на робочу папку активного проєкту.
- **Створення та редагування файлів (`create_or_update_file`):**
  - `«створи файл notes.txt зі списком покупок»`
  - `«онови файл README.md і додай опис ліцензії»`
- **Перегляд файлів та директорій (`read_file_or_dir`):**
  - `«покажи файли в папці src»`
  - `«прочитай вміст package.json»`

### 7. 🛡️ Шлюз Безпеки (SafetyPolicy) та Запуск Програм

Система автоматично класифікує ризик кожної дії та запобігає небезпечним операціям.

- **Безпечні дії (Allowlist — виконуються без підтвердження):**
  - **Запуск програм:** `«відкрий калькулятор»`, `«запусти telegram»`, `«відкрий obsidian»`, `«запусти термінал»`.
  - **Діагностика:** `ls`, `git status`, `git diff`, `git log`, `pwd`, `date`, `df -h`.
  - **Керування звуком:** `pactl`, `wpctl`, `pamixer`, `amixer`, `osascript`.
- **Ризиковані дії (Confirm — вимагають натискання кнопки «Підтвердити»):**
  - Виконання довільних скриптів (`python3 script.py`, `./build.sh`).
  - Деструктивні команди терміналу (`rm -rf`, модифікація системних файлів).
  - Будь-які модифікації файлів після того, як маскот прочитав зовнішній веб-сайт (захист від непрямих ін'єкцій).
- **Заборонені дії (Deny — блокуються безумовно):**
  - Спроби запуску з правами суперкористувача (`sudo`, `su`).
  - Доступ до приватних ключів (`~/.ssh`, `id_rsa`), паролів та файлів секретів (`.env`, `config.env`).

### 8. 🧠 Локальна Автономна Пам'ять (Memory & Context)

Маскот зберігає довгострокові факти та історію попередніх діалогів локально у файлі `~/.config/local-helper-ai/memory.json`:
- **Ковзне вікно контексту (`recent_messages`):** зберігає останні 10 реплік (5 пар діалогу), щоб ви могли продовжити розмову після перезапуску програми чи комп'ютера.
- **Довгострокові факти (`facts`):** зберігає важливі деталі про вас, проєкти та уподобання (до 25 фактів із автоматичною дедуплікацією).
- **Керування природною мовою:**
  - *«Запам'ятай, що мій дипломний проєкт у ~/projects/diploma»*
  - *«Що ти про мене пам'ятаєш?»* — виведе список фактів.
  - *«Забудь про диплом»* — видалить факт.
  - *«Очисти пам'ять»* — скине збережені факти та історію.
- **Нульові приховані витрати токенів:** Пам'ять завантажується та зберігається суто локально і займає не більше 600–700 токенів у запиті.

### 9. 🪟 Інтерфейс, Анімації та Зручність

- **Поверх усіх вікон (Always on Top):** Маскот завжди знаходиться на екрані поруч із вами (підтримка X11 та GNOME Wayland).
- **Вільне перетягування:** Затисніть ліву кнопку миші на касці персонажа і перетягніть його в будь-який куток дисплея.
- **Авто-позиціонування:** При відкритті поля вводу біля краю екрана маскот акуратно зсувається, щоб не виходити за межі монітора.
- **5 живих станів маскота:**
  - `IDLE` — спокійно дихає та моргає.
  - `IDLE (Музика 🎧)` — коли у системі грає музика, одягає жовто-чорні навушники, бере валізку та танцює в ритм під неоновим фіолетовим сяйвом.
  - `THINKING` — обдумування відповіді або плану дій.
  - `WORKING` — стукає молотком по інструментах під час виконання команд.
  - `SUCCESS` — радісна реакція на успішне завершення.
  - `ERROR` — повідомлення про помилку чи потребу ввести ключ.
- **Плавна стабільна хмаринка діалогу:** Хмаринка не блимає і плавно трансформує вміст між кроками мислення, виконання та фінальної відповіді.
- **Розгортання вікна відповідей (`ChevronsUpDown`):** Кнопка зі стрілочками вгорі хмаринки перемикає розмір між компактним (105px) та розгорнутим (295px) для комфортного читання довгих конспектів і коду.
- **Тонкий акуратний скролбар:** 4-піксельний напівпрозорий повзунок, що з'являється лише за потреби.
- **Швидке закриття:** Клавіша `Esc` або хрестик `✕` миттєво ховають хмаринку або рядок вводу.
- **Системний трей:** Іконка в треї дозволяє в один клік сховати/показати асистента або вийти з програми.

## 🧑‍💻 Інструкція для розробників (Збірка з вихідного коду)

Якщо ви хочете самостійно зібрати проєкт або внести модифікації:

### 1. Системні вимоги (Ubuntu / Debian)
```bash
# Встановлення Rust
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y
source "$HOME/.cargo/env"

# Необхідні C/GTK бібліотеки
sudo apt update && sudo apt install -y build-essential curl wget file libssl-dev libgtk-3-dev libwebkit2gtk-4.1-dev libayatana-appindicator3-dev librsvg2-dev
```

### 2. Встановлення залежностей проєкту
```bash
npm install
```

### 3. Запуск у режимі розробки (Hot-reload)
```bash
npm run tauri dev
```

### 4. Збірка релізного .deb пакета
```bash
npm run build:deb
```
Готовий deb-пакет буде скомпільовано та збережено у:
`releases/local-helper-ai_0.3.2_amd64.deb`
