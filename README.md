# Local Helper Mascot 🤖🔨

Десктопний локальний AI-асистент та анімований маскот на базі **Tauri v2 + React 18 (TypeScript) + Tailwind CSS + Framer Motion**, що використовує мультимодальний інтелект **Google Gemini 2.5 API** та виконує локальні операції на вашому комп'ютері через надійні асинхронні команди Rust.

![Mascot Preview](public/mascot/idle.png)

---

## ⚡ Швидкий старт для користувачів (.deb пакет)

Найпростіший спосіб користуватися Local Helper Mascot на **Ubuntu, Debian, Linux Mint** або будь-якому дистрибутиві на базі Debian.

### 1. Завантаження та встановлення

Готовий `.deb` пакет знаходиться у репозиторії в папці `releases/`:

```bash
# Встановлення завантаженого deb-пакета
sudo dpkg -i releases/local-helper-ai_0.1.0_amd64.deb

# Якщо системі потрібні залежності (GTK3 / WebKit2GTK):
sudo apt-get install -f -y
```

Після встановлення програма з'явиться у вашому **системному меню додатків** як **"Local Helper Mascot"**, а в терміналі стануть доступні команди `local-helper-ai` та швидка утиліта `addkey`.

## 🔑 Як отримати безкоштовний Gemini API ключ

Маскот використовує офіційний Google Gemini API. Для роботи достатньо безкоштовного тарифу (Free Tier), який надає Google.

### Покрокова інструкція:

1. **Перейдіть на сайт Google AI Studio:**  
   👉 [https://aistudio.google.com/](https://aistudio.google.com/)
2. **Увійдіть під своїм Google-акаунтом.**
3. У верхньому лівому кутку натисніть синю кнопку **"Get API key"** (або "Create API key").
4. Натисніть **"Create API key in new project"** (або виберіть існуючий проєкт Google Cloud).
5. Скопіюйте створений ключ (він починається на `AIzaSy...`).

> [!NOTE]  
> Ключ зберігається виключно на вашому власному комп'ютері у локальному файлі конфігурації `~/.config/local-helper-ai/config.env` і ніколи не передається третім особам.

## 💻 Налаштування через термінал (`addkey` та CLI)

Після встановлення `.deb` пакета ви можете легко керувати всіма налаштуваннями прямо з терміналу:

### 1. Додати або оновити Gemini API ключ:

```bash
# Швидке додавання ключа прямо в команді:
addkey AIzaSyВаш_Ключ_З_Google_AI_Studio

# Або виконайте команду без аргументів для інтерактивного вводу:
addkey
```

*(Також працює альтернативний синтаксис: `local-helper-ai addkey <КЛЮЧ>`)*

### 2. Змінити модель Gemini:

За замовчуванням використовується швидка мультимодальна модель `gemini-2.5-flash`. Ви можете перемкнути її на будь-яку іншу:

```bash
# Перемкнути на флагманську модель для складних міркувань:
local-helper-ai set-model gemini-2.5-pro

# Повернути швидку модель:
local-helper-ai set-model gemini-2.5-flash
```

### 3. Підключити сховище нотаток Obsidian (Obsidian Vault):

Вкажіть маскоту, де знаходиться ваше сховище Obsidian, щоб він міг автоматично додавати задачі та ідеї у ваш канбан:

```bash
local-helper-ai set-vault ~/Documents/Obsidian/MyVault
```

### 4. Переглянути поточну конфігурацію:

```bash
local-helper-ai config
```

Ви побачите статус усіх параметрів:
```text
==================================================
🤖 Local Helper Mascot — Поточна конфігурація
==================================================
📁 Файл конфігурації : /home/user/.config/local-helper-ai/config.env
🔑 Gemini API Key    : AIzaSy...xxxx (Встановлено ✅)
🧠 Модель Gemini     : gemini-2.5-flash
📝 Obsidian Vault    : /home/user/Documents/Obsidian/MyVault ✅
==================================================
```

### 5. Змінити будь-який довільний параметр:

```bash
local-helper-ai set ІМ'Я_ПАРАМЕТРА ЗНАЧЕННЯ
```

### 6. Довідка за всіма командами:

```bash
local-helper-ai --help
```

## 🛠️ Можливості та як користуватися маскотом

### 1. Вікно та взаємодія
- **Always on Top (Поверх усіх вікон):** Маскот завжди знаходиться на екрані поруч із вами (підтримується робота у Wayland та X11).
- **Перетягування вікна:** Затисніть ліву кнопку миші на маскоті та перетягніть його у будь-який зручний куток екрана.
- **Відкриття / закриття вводу:**
  - Одинарний клік по маскоту відкриває акуратний рядок запиту.
  - Повторний клік або клавіша `Esc` ховають рядок вводу.
- **Розумне авто-позиціонування:** Якщо вікно розміщено біля самого низу або правого краю монітора, при відкритті поля вводу маскот автоматично підводиться вгору/вліво, щоб елементи не виходили за межі екрана, і плавно повертається назад після закриття.
- **Системний трей:** Іконка в панелі задач дозволяє в 1 клік тимчасово приховати/показати помічника або завершити роботу (`Вийти`).

### 2. 5 живих станів маскота
- **IDLE** — маскот спокійно дихає та моргає.
- **THINKING** — обдумування відповіді або плану дій.
- **WORKING** — активне виконання операцій (стукає молотком по інструментах).
- **SUCCESS** — успішне виконання завдання.
- **ERROR** — повідомлення про помилку або відсутній ключ.

### 3. Голосове введення (Мікрофон) 🎙️
- Натисніть кнопку мікрофона поруч із рядком вводу.
- Надиктуйте запит українською мовою (наприклад: *"Запиши задачу доробити дизайн на четвер"*).
- Натисніть кнопку ще раз (або Enter) — запис зупиниться, аудіо буде надіслано в Gemini, і дія виконається автоматично.

### 4. Зображення, фото та скриншоти 📸
Маскот підтримує прямий аналіз зображень через Gemini Vision:
- **Швидка вставка з буфера обміну (`Ctrl+V` або `Ctrl+М` в укр. розкладці):** просто зробіть скриншот або скопіюйте картинку в браузері та натисніть `Ctrl+V`.
- **Drag-and-Drop:** перетягніть файл зображення прямо на маскота.
- **Іконка скріпки 📎:** класичний вибір файлу з диска.

### 5. Інтеграція з Obsidian Kanban 📋
Маскот спеціалізується на веденні канбан-дошки у файлі `TODO.md`:
- **Задачі в колонку `## TO DO`**: розуміє дедлайни з природної мови (*"купити молоко на вівторок"*, *"підготувати звіт до п'ятниці"*) і автоматично конвертує їх у синтаксис Obsidian Kanban `@{YYYY-MM-DD}`.
- **Ідеї в колонку `## Ideas`**: зберігає концепції, ідеї для проєктів та думки без зайвого сміття.

### 6. Робота з файлами та терміналом 💻
- `append_to_obsidian` — додавання записів у файл нотаток.
- `create_or_update_file` — створення скриптів, конфігів або документів.
- `read_file_or_dir` — перегляд коду, списку файлів або вмісту директорій.
- `run_cli_command` — виконання системних команд (статус git, перевірка процесів тощо).

## 🧑‍💻 Інструкція для розробників (Збірка з вихідного коду)

Якщо ви хочете самостійно зібрати проєкт або внести модифікації:

### 1. Системні вимоги (Ubuntu / Debian)
```bash
# Встановлення Rust
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y
source "$HOME/.cargo/env"

# Необхідні C/GTK бібліотеки
sudo apt update && sudo apt install -y build-essential curl wget file libssl-dev libgtk-3-dev libwebkit2gtk-4.1-dev libayatana-appindicator3-dev librsvg2-dev
```

### 2. Встановлення залежностей проєкту
```bash
npm install
```

### 3. Запуск у режимі розробки (Hot-reload)
```bash
npm run tauri dev
```

### 4. Збірка релізного .deb пакета
```bash
npm run build:deb
```
Готовий deb-пакет буде скомпільовано та збережено у:
`releases/local-helper-ai_0.1.0_amd64.deb`
